SYLVER SOUL — VOID
Interactive scroll-driven opening study (prototype 01)

HOW TO VIEW
1. Open index.html in any modern desktop browser (Chrome, Edge, Firefox).
2. Scroll gently to control the light trail, reaching hand, and the final fade.
3. The drop and leaf motion play independently on loops.
4. Click 'Tune' in the bottom right to alter trail visibility or its video sync.

WORKFLOW NOTES
- All visual footage comes from four supplied renders, compressed for browser performance.
- 'Drop_Gold' and 'Leaf_Shine' play on loops.
- 'Gold_Trail' is a scroll-scrubbed, screen-blended video plus a continuous SVG guide
  path, which lets the light visibly cross panel edges. The bright leaf panel
  sits in front of the trail so it temporarily passes beneath it.
- 'Reach' is scroll-scrubbed and fades into the last 'I was nothing' panel.
- Draft first-person narration is intentionally short and can be edited.
- No audio is included in this study, so it can be paced by scrolling.
- Uses only local media files: no account, server, fonts, or external libraries.

LIMITATIONS / NEXT PASS
The source trail is projected as a pseudo-alpha luminance blend. The added
SVG path supplies continuity between panels. It is a direction/interaction
prototype, not pixel-perfect optical-flow tracking of the trail's brightest
point. The footage timeline, panel positions, and narration can be retimed.
